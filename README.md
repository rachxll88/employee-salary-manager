Employee Salary Manager

A simple Java console application for practicing collections, methods, OOP basics, and exception handling.

Features
Store employees in an ArrayList
Find employees with a salary above a specified limit
Calculate total salary
Find the highest-paid employee
Find the lowest-paid employee
Create a HashMap with employee names and salaries
Get unique employee names with HashSet
Handle invalid negative salaries with IllegalArgumentException

Technologies
Java 21
IntelliJ IDEA
ArrayList
HashSet
HashMap
OOP basics
Exception handling

Example output
[Kate, Anna]
260000
Anna 80000
Alex 50000
{...}
[Alex, Mike, Kate, Anna]
Salary cannot be negative

Purpose

This is a learning project created to practice core Java concepts through a small practical application.
